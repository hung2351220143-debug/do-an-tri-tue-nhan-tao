### `animate-gradient-shift` dead animation on Home CTA

The closing CTA section in `Home.vue` is:

```html
<section class="py-16 px-4 bg-gradient-to-r from-green-600 via-emerald-600 to-teal-600 bg-size-200 animate-gradient-shift">
```

The `gradientShift` keyframe animates `background-position` from `0% 50%` to `100% 50%`. This only produces a visible shift when `background-size` is wider than the element — typically `200% 200%`. The class `bg-size-200` is a Tailwind JIT arbitrary-value pattern that is not part of the default config, and there is no `backgroundSize` extension in `tailwind.config.js` for it. `style.css` also has no rule targeting that class or the section. Tailwind will not generate the class, so `background-size` remains at its default `auto`, and the animation does nothing visible.

All other animation usages — `animate-float`, `animate-fade-in-up`, `animate-scale-in`, `animate-pulse-glow` — are properly defined in both `tailwind.config.js` and `style.css`.

</details>
